# 📌 Основное назначение
Автономная портативная утилита для Windows, дающая полный контроль над раздельной раскладкой, знаками препинания, автозагрузкой и кастомными макросами.

1. **Раздельное переключение языков (Punto-style):** Позволяет избавиться от циклического переключения раскладки. Задаётся двумя независимыми клавишами в файле настроек. По умолчанию: одиночное нажатие Right Shift жёстко включает русскую раскладку, а одиночное нажатие Left Shift — английскую. Зажатие клавиш для ввода заглавных букв ложных переключений не вызывает.

2. **Унификация знаков препинания (FixDotMode):** Клавиша с символами `/` и `?` (SC035 возле правого Shift) настраивается тремя режимами в INI-файле:
    - `FixDotMode=0` — Выключено (стандартное поведение Windows).
    - `FixDotMode=1` — Безусловная унификация. Одиночное нажатие ВСЕГДА ставит точку (.), а с зажатым Shift — ВСЕГДА ставит запятую (,) в любой раскладке.
    - `FixDotMode=2` — Унификация + модификаторы. Одиночное нажатие пишет точку (с Shift — запятую), но при удержании: Любой Alt + точка = бесконечный ввод слэшей (/), Любой Ctrl + точка = знак вопроса (?).

3. **Умная вставка чистого текста (PastePlain):** По нажатию `Ctrl + Alt + V` скрипт забирает текст из буфера обмена, полностью очищает его от форматирования и мгновенно вставляет в активное окно. Перед вставкой программа сама сканирует текст: если там есть кириллица — она автоматически включает русский язык в активном окне, предотвращая превращение русских букв в кашу в OneNote.

4. **Кастомизация макросов и фраз (CustomAltGr):** Позволяет привязать к удержанию Правого Альта (AltGr) любой символ, формулу или длинную текстовую фразу. Настройка задается в одноименном разделе конфигурационного файла для кнопок от 1 до 0, а также минус и плюс. Пустые поля игнорируются.
    - По умолчанию в раздел вшиты: `Key_8=₽`, `Key_9=м²`, `Key_0=°` и `Key_Equal=≈`. Они аппаратно защищены и работают на любой раскладке.
    - Если фраза должна начинаться или заканчиваться пробелами, её необходимо обернуть в двойные кавычки: `Key_Minus=" ₽ с НДС 22%"`.
    - **Динамическая шпаргалка-меню:** При зажатии и удержании Правого Альта прямо над системными часами (в правом нижнем углу экрана) автоматически всплывает аккуратная горизонтальная полоска, показывающая текущие настройки всех макросов. При отпускании клавиши панель мгновенно исчезает.

## ⚙️ Инструкция по настройке параметров (KeyboardSwitcher.ini)

Конфигурационный файл автоматически создаётся в кодировке UTF-8 при первом запуске утилиты рядом с исполняемым файлом.

- **Смена клавиш переключения раскладки:** Доступные кнопки для ввода в параметры `RussianKey` и `EnglishKey`: `RShift`, `LShift`. Если ввести `0` или оставить поле пустым — переключатель для этого языка полностью отключается.
- **Интерактивное управление через трей:** Пункт «Открыть настройки» в меню иконки у часов запускает INI-файл в Блокноте и замораживает работу скрипта. В момент закрытия Блокнота программа автоматически перечитывает новые параметры на лету, избавляя от необходимости перезапускать `.exe` вручную.

- **Умная автозагрузка (AutoStart):** Настройка `AutoStart=1` автоматически создаёт задачу в Планировщике Windows для запуска скрипта с наивысшими правами администратора при входе в систему. Если у скрипта нет прав администратора при изменении этого параметра, программа выведет чёткое предупреждение, сама откроет папку со скриптом в Проводнике и выгрузится из памяти для перезапуска от имени Администратора.
